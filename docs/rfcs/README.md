# RFCs

Required for any change to `wit/` from 0.3 onward, and encouraged before that for anything larger than a bug fix. Process:

1. Open a tracking issue labelled `area:contract`.
2. Copy `0000-template.md` to `NNNN-short-title.md` in a PR.
3. Comment period: two weeks minimum; the maintainer announces a final comment period of one week.
4. Accepted RFCs get an ADR summarising the decision; the RFC remains the design record.

An RFC without a credible **Native host** mapping is not accepted, even while the Native host does not exist. That rule is what keeps the webview host from becoming the definition of Bezel.
